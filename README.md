# Gym

Personal workout app for Android. Open https://adiworksdev.github.io/Gym/ and use your browser’s Add to home screen option.

Workout records stay on your device. Use Settings to export regular backups.

Exercise data by RepDB (repdb.co): https://repdb.co. Selected illustrations are used inside this app under REPDB-LICENSE.md, not offered as a reusable dataset. See THIRD-PARTY-NOTICES.txt.
